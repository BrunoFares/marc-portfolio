# 2.1.2 Common theorems and methods for congruence
(1) Euler’s function
For positive integer n, the Euler function ϕ(n) denotes the number of pos-
itive integers coprime to and less than n. Evidently, the number of residue
classes coprime to n and the number of elements in a reduced residue system
modulo n are also ϕ(n).
