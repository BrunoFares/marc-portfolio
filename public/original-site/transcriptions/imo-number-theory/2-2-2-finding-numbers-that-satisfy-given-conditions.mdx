(a,c) which satisfies $c < b$, and 2a + c < 2a + b, a contradiction. If $b < a$,
then by property (2), (b,a) is also a “bad pair,” leads to 2b+a < 2a+b, a
contradiction.
All these show that such a “bad pair” does not exist. Therefore $a = b.$
Remark. The main idea is similar to a previous problem using Vieta’s
formula for constantly finding smaller solutions. In the latter half, we can
also choose such a pair (a,b) for which a + b is the least instead of 2a + b.
If $a < b$, then the contradiction can be obtained from property (1); or
$a > b.$ Using property (2) and then property (1), we can also obtain the
contradiction.
